# 🚀 Lead Engine (Google Maps Automation)

An automated lead generation system that extracts business data from Google Maps and stores it in Google Sheets for outreach.

## 🔥 Features

- Scrapes businesses by keyword + location
- Extracts:
  - Name
  - Phone
  - Website
  - Rating
- Filters leads (rating ≥ 2)
- Stores data in Google Sheets
- Designed for cold calling workflows

## ⚙️ Tech Stack

- n8n (automation)
- Google Sheets API
- Web scraping (Apify / Outscraper / Puppeteer)

## 🧩 Workflow

1. Input: keyword + country
2. Fetch business listings
3. Extract structured data
4. Filter leads
5. Store in Google Sheets
